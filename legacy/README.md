# Legacy 2-D provenance

The supplied ZIP contains an older 2-D acceleration/point-robot prototype. A local,
ignored `source_snapshot/` was selectively extracted for audit without running it or loading
pickle-based `.pt` files. It is not the paper-reference vessel model and is not linked into
the new code.

Redistribution rights were not supplied, so the snapshot is intentionally ignored by Git.
Before public release, the owner must either confirm a compatible license or keep only this
independent factual audit and remove the local snapshot.
