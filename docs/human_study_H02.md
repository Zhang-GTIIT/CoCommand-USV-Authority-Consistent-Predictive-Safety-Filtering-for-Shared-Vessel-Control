# H02 human-participant protocol preparation

Status: protocol interface only; ethics and study-design decisions pending.

Planned records contain an anonymous session ID, condition/order code, controller version,
joystick calibration hash, training completion, withdrawal flag/time, command and takeover
events, and separately permissioned questionnaire/interview records. Do not store names or
contact details in experiment logs.

Conditions should use counterbalanced/crossover order where appropriate and identical
scenario/command opportunities. The research questions concern perceived control authority,
conflict, workload, comfort, and trust; quantitative command fidelity is not a substitute for
those outcomes. Sample size, instruments, consent language, recruitment, compensation, data
retention, anonymization, adverse-event procedure, and withdrawal rules require ethics and
research-owner approval.

No questionnaire answers, participant count, or participant result is generated here. Start
with desktop simulation after approval; occupied/crewed water testing is outside this software
deliverable and needs a separate risk assessment and authorization.
