# 二维 SLAM 建图：运行指引

Windows 10/11 x64。包内已包含 Python 和依赖，无需安装、联网或连接硬件即可体验建图。

## 启动与操作

1. 完整解压 ZIP，打开 `CoCommand-SLAM` 文件夹。不要在压缩软件内部运行。
2. 双击 `01_START_SIMULATION.cmd`，看到窗口后按 **Enter** 启用。
3. **W/S** 调油门、**A/D** 转向，移动过程中自动扫描、估计位置和航向、更新地图。
4. **Space** 停止输入，**F5** 保存，**Esc** 保存并退出。窗口失去焦点后需重新 Enter 启用。

| 入口 | 用途 |
|---|---|
| `01_START_SIMULATION.cmd` | 键盘或手柄移动采集，实时 SLAM 建图 |
| `02_START_DEMO.cmd` | 自动移动并演示建图 |
| `03_REPLAY_EXAMPLE.cmd` | 重放包内 300 帧模拟扫描，从零重新建图 |
| `04_C1_LIVE.cmd` | 接入真实 RPLIDAR C1，选择 COM 端口，实时采集和建图 |

手柄连接后按 **J** 切换输入，**C** 开始校准，移动两轴至两端再回中，按 **C** 完成，然后 Enter 启用。配置模板在 `app/configs/gamepad.json`。默认不发送任何真实推进器命令。

## 看图与保存

左上为模拟采集场景，左下为当前扫描，右侧为 **SLAM 独立估计**的地图和轨迹。白色为自由区域，灰色为未知，黑色为占据区域。场景墙面和几何物体只提供建图参照；SLAM 不读取仿真真实坐标。

每次运行的结果位于 `output/时间-模式/`：`scans.jsonl` 为扫描记录（回放模式不重复录制），`map.pgm`/`map.npz` 为地图，`trajectory.csv` 为估计轨迹，`summary.json` 为摘要。正常退出另存截图。

回放自己的扫描记录，在解压目录打开 PowerShell：

```powershell
.\.runtime\python.exe -I .\app\launch_lidar2d.py replay --file "output\某次记录\scans.jsonl"
```

## 接入数据

连续、符合接口格式的二维扫描可以直接进入 SLAM。每帧包含时间、角度、距离、质量和有效标记；统一单位是米、弧度，坐标为 x 前、y 左、航向逆时针。程序录制的 JSONL 可直接回放，其它数据需先转换。示例是合成数据，不是水池实测。

C1 使用官方 SDK 桥接，默认 **460800 / 8N1**。接好供电和 USB 转串口适配器后运行 `04_C1_LIVE.cmd`，输入实际 COM 端口；USB 适配器可能需要厂商驱动。原始顺时针角度与毫米距离在驱动中统一转换。**真实 C1 和实体手柄尚未实机验证。**

## 常见问题

- 船不动：松开按键、输入回中，再按 Enter；确认窗口有焦点。
- 无串口或连接失败：检查供电、数据线、适配器驱动、COM 端口及是否被其它程序占用。
- `STALE / WAITING FOR SCAN`：没有新扫描，显示的是最后一次地图；检查数据源。
- `LOST / DEGENERATE`：减速并保持多方向静态几何可见，必要时按 **R** 重新建立地图原点。
- 地图漂移：纯激光局部匹配在空旷、对称、动态或快速运动场景中可能失效；当前没有全局回环和扫描运动去畸变。

`app/` 只包含此 SLAM 平台的源码、采集桥接、示例和测试；`.runtime/` 是运行所需的 Python 与依赖，两者请完整保留。源码在 `app/src/cocommand2d/`，版本和许可证位于 `app/meta/`。不包含主项目研究算法、历史实验、部署脚本或论文资料。
